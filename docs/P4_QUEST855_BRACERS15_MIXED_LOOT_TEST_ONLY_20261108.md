It does **not prove** that a particular player released their window, their packet was sent/received, `OnPatchValuesUpdate` ran, or a client's sparkle was repainted; taking a normal item is not itself this same release call. The seventh source-only Python test checks those pinned original functions. This is **not** a runtime repair or approval to call `ForceValuesUpdateAtIndex` on arbitrary map threads.
