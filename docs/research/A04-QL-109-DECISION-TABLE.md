## How to read a cell

Two different effects:

- **Socket deny.** `CanPacketReceive` returns false for one `CMSG_AUTOSTORE_LOOT_ITEM` slot (`Opcodes.h:294`, value `0x108`). The hook is `QuestLootProtection.cpp:205-226`. The false return is `QuestLootProtection.cpp:194`. It runs at `WorldSession.cpp:461`, before `opHandle->Call` at `WorldSession.cpp:464`. It does not hide the loot row or the corpse sparkle, and it does not change the shared `LootItem`.
- **Hide.** The loot row is omitted, or the corpse sparkle is off, for that viewer. Core does this in `LootView` and `Player::isAllowedToLoot`. This module does not.

A cell that is neither is a **permit**: the click is accepted and the row stays visible. `Player::StoreLootItem` (`Player.cpp:13861`) can then put the item in the bag. That store is not a sparkle.
